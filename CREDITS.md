# Credits

still-online ships **no copied assets**. Everything in `src/assets/` and `public/` is one of:

- original work (CSS, hand-written SVG, sounds synthesized with the Web Audio API), or
- a file under a **CC0** or **CC BY 4.0** license, credited below.

No Microsoft, MSN, Winamp, MySpace or Netlog logos, icons, sounds, wallpapers, skins or fonts are used.
