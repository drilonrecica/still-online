# P0 — Foundations: gate review

## What was built

- **P0-01** v0.2 architecture (`docs/architecture-v0.2.md`), shared types, `src/os/random.ts` (`mulberry32`) and `tests/e2e/helpers.ts`.
- **P0-02** Start menu programs + shortcuts: `category`/`pinned` on apps, an "All Programs" flyout with category submenus (click or keyboard), data-driven desktop/Start shortcuts that can carry window props.
- **P0-03** Blob store (`src/os/blobStore.ts`) on IndexedDB with a memory fallback, `useBlobUrl(key)`; Reset clears it.
- **P0-04** Virtual file system: persisted `fs` store (folders, files, Recycle Bin, seed merging that never resurrects purged seeds) and the procedural photo renderer.
- **P0-05** `FolderView` UI, the `explorer` app (My Documents / Pictures / Music) and the Recycle Bin rebuilt on the fs.
- **P0-06** World/day engine: persisted `world` store, day counter, advance rules, unlocks, `world:dayChanged`.
- **P0-07** Network core: offline / dialing / online state machine, `requireOnline()`, events.
- **P0-08** Idle detection: `onIdle(minutes, cb)`, `os:idle` / `os:active`.
- **P0-09** Shared content lint + `linkify` for `*.example` links; Messenger rich text links open Web Explorer via `browser:open`.

## How to try it

1. `npm run dev` (add `?speed=fast` to scale the clock), boot, log on.
2. **Start → All Programs**: hover or arrow into Accessories / Internet / Entertainment / System Tools.
3. Double-click **My Documents**: browse, rename, delete a file, switch Icons / Details.
4. Open **Recycle Bin** (desktop or Start menu): Restore a file or Empty Recycle Bin.
