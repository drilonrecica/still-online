# P5 — Creative and media: gate review

## What was built

- **P5-01** Paint: toolbox (select, eraser, fill, picker, magnifier, pencil, brush, airbrush, text, line, rectangle, ellipse, rounded rectangle), 28-colour box, undo/redo, Image → Attributes, open/save to My Pictures, set as wallpaper (tiled/centered) and as display picture. Drawing logic is plain TS on a `PixelBuffer`, unit-tested.
- **P5-02** Snapshot Booth: consent screen, webcam mode with 8 filters and a 3-2-1 countdown + flash, a cartoon-me fallback (hair/eyes/mouth buttons) when the camera is denied or declined, photos saved to My Pictures with "Set as display picture".
- **P5-03** Amplifier skins (Brushed Metal, Neon Night, Bubblegum, via `SKN` and the titlebar context menu) and the windowshade strip (titlebar double-click).
- **P5-04** Amplifier equalizer: preamp + 10 biquad bands built once per audio element, ON/AUTO, 8 presets, persisted, panel stacks with the playlist.
- **P5-05** Playlist editing (remove, reorder, add from My Music / shipped tracks), `amplifier:enqueue` respects the edited list, and the "Burn CD…" joke with its buffer underrun.
- **P5-06** A second `nowPlaying2` script for every friend, track-specific where funny.

## How to try it

1. `npm run dev`, open `/?speed=fast`, boot, log on.
2. Start → **Paint** (pinned): draw, File → Save As, File → Set As Background.
3. Start → All Programs → Accessories → **Snapshot Booth**: pick "No camera — use a cartoon me", try filters, Take Photo.
4. Open **Amplifier**: press `SKN` to cycle skins, `EQ` for the equalizer, double-click the titlebar for the windowshade, `PL` → MISC → Burn CD…
5. In Messenger tick "Show what I'm listening to" and play tracks to see the new reactions.
