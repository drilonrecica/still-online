# v0.3 P0 — i18n foundations: gate review

## What was built

- **P0-01** i18n architecture: `docs/i18n.md`, shared types, `common` catalog area.
- **P0-02** i18n core: `t()` / `useT()` / `useLocale()`, detection, typed `MessageKey`s.
- **P0-03** Locale formatting: time, date and number formatting per locale.
- **P0-04 / P0-05** Language-neutral persistence for windows, fs, mail, settings, web and Messenger transcripts, migrated inside each store's `sanitize` (no save wipe).
- **P0-06** Per-locale content overlays with English fallback.
- **P0-07** Language UI: login picker ("Language / Sprache"), Regional and Language Options app, `EN`/`DE` tray badge with a menu.

## How to try it

1. `npm run dev` (add `?speed=fast` to scale the clock), click through boot.
2. On the login screen use **Language / Sprache** → Deutsch; reload and the choice persists.
3. Log on, then **Start → All Programs → System Tools → Regional and Language Options**: pick a language, **Apply**; title, buttons and the example line change live.
4. Click the **EN/DE** badge in the tray and pick the other language; open windows and the clock follow.
