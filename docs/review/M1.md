# M1 — XP shell: gate review

## What was built

- **M1-01** Shell architecture doc, `src/os/types.ts`, `events.ts`, `clock.ts` (fixed 2007 clock, Feb 29 rule).
- **M1-02** xp.css + design tokens, global reset, CSS-only Bliss-like wallpaper.
- **M1-03** Window manager store (open/close/focus/minimize/maximize/move/resize, singleInstance, cascade, off-screen clamping).
- **M1-04** `Window` component (drag, buttons, focus on mousedown).
- **M1-05** App registry + starter apps: My Computer, Notepad, Recycle Bin.
- **M1-06** Desktop icons (select, deselect, open, keyboard).
- **M1-07** Taskbar: Start button, window buttons, tray with mute toggle and 2007 clock.
- **M1-08** Start menu (programs, My Computer / Recycle Bin, Log Off, Turn Off Computer).
- **M1-09** Boot, login and session flow (boot → login → desktop → off).
- **M1-10** Synthesized sound service (startup, logon, logoff, error, notify, nudge, click).
- **M1-11** Persistence (`still-online:v1:<store>` keys, version mismatch resets).
- **M1-12** Shell E2E spec (`tests/e2e/shell.spec.ts`).

## How to try it

1. `npm ci`, then `npm run dev`.
2. Click the boot screen to skip, type a name, click the user tile.
3. Double-click Notepad, type, drag the title bar, minimize via the taskbar and restore.
4. Open the Start menu; try Log Off and Turn Off Computer; click the black screen to power on.
5. Reload: your name and Notepad text persist.

- `npm run verify` and `npm run e2e`: pass.
- `@review` specs (`review-m0`, `review-m1`): pass, no console errors or warnings.

## Fixes made in this gate

- Title-bar text rendered in a serif font where Trebuchet MS isn't installed (xp.css names no fallback); added a sans-serif stack in `src/os/theme/global.css`.
- Desktop icon and Start menu entry for Notepad read "Untitled - Notepad"; added optional `AppDefinition.label` ("Notepad") used by both, window title unchanged.
- Login "Your name" field label used the pixel font and looked cramped; it now inherits the login font.
- `tests/e2e/review-m0.spec.ts` was stale (the scaffold heading is gone); it now asserts the boot screen.
- Added `tests/e2e/review-m1.spec.ts`.

## Known gaps and follow-ups

- Windows have square bottom corners and no resize handles beyond what M1-04 specified; polish candidate for M4.
- The Start menu's left "programs" pane is sparse with a single entry; it fills out as apps arrive in M2/M3.
- Sounds were not audited by ear in this headless gate.
