# P1 — Desktop and system: gate review

## What was built

- **P1-01** 11 procedural homage wallpapers (9 + 2 easter eggs) rendered to cached data URLs; the desktop reads `wallpaper` / `wallpaperPosition`.
- **P1-02** Display Properties: Themes, Desktop (gallery, Browse…, position, colours), Screen Saver, Appearance (Blue / Olive / Silver); Konami unlock.
- **P1-03** Screensavers: Pipes, Flying Panes, Marquee, My Pictures Slideshow; idle start, input stop, reduced-motion still screen.
- **P1-04** Tray balloon tips: one-at-a-time queue, seen-once ids, scheduled content.
- **P1-05** Dial-up dialog, synthesized modem handshake, tray network icon (Disconnect / Status); Messenger sign-in auto-dials.
- **P1-06** Fake system content: documents, photos, music and Recycle Bin seeds.
- **P1-07** Notepad opens, saves and saves-as fs files; the old single document migrates to `My Documents/notes.txt`.
- **P1-08** Disk Cleanup: endless scan, joke categories, frees 0 KB.

## How to try it

1. `npm run dev` (add `?speed=fast` to scale the clock), boot, log on.
2. Right-click the desktop → **Properties**: switch tabs, pick a theme, **Preview** a screensaver.
3. Click the tray network icon: the dial-up dialog connects and a "Connected at 56.0 Kbps" balloon appears.
4. **Start → All Programs → System Tools → Disk Cleanup**.
5. Open a `.txt` from My Documents; it opens in Notepad (`<name> - Notepad`).
