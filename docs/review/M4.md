# M4 — Release v0.1.0: gate review

## What was built

- **M4-01** Accessibility pass: `@axe-core/playwright` checks (`tests/e2e/a11y.spec.ts`) for login, desktop with Start menu open, Messenger chat and Amplifier; serious/critical violations fixed; keyboard path login → Start → Messenger → chat → close covered by an e2e test.
- **M4-02** Performance pass: every app is lazy-loaded from the registry; the initial JS chunk is 183.8 kB raw / **60.0 kB gzip** (budget 250 kB gzip); window drag uses `transform` and commits on pointer-up; music uses `preload="none"`.
- **M4-03** Small-screen notice: XP-style dialog under 900 px or on coarse pointers, dismissal remembered.
- **M4-04** README with screenshots (`docs/screenshots/`), honest "Planned" section, disclaimer and credits link.

## How to try it

1. `npm run dev`, open `http://localhost:5173/still-online/`, skip boot, enter a name.
2. Open Messenger, sign in, wait for contacts to sign in and message you.
3. Open Amplifier, press play, toggle PL; tick "Show what I'm listening to" in Messenger.
4. Resize the browser under 900 px wide and reload (clear site data) to see the small-screen notice.

## Known gaps and follow-ups

- Netlog/MySpace-style profiles and the "living world" are not built (listed under "Planned" in the README).
- Sounds and real MP3 playback were not auditioned by ear in headless gates.
- Mobile/touch is only a notice; the UI is not adapted to small screens.
