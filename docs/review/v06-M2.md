# v0.6 M2 — apps on touch gate

M2 adapts the apps to touch. This gate checked every app on a phone (412×915 portrait, 915×412 landscape) and a tablet (1024×768), in English and German. It also checked four websites in Web Explorer on a phone, one phone set as a boy, and one desktop shot against v0.5. It applied the gate procedure and the touch rubric.

## What was built

- **M2-01:**
  - **Messenger:** contact list, a full-screen chat with wrapping replies and the input pinned above the keyboard, and the emoticon picker within 92vw.
  - **Mail:** stacked phone layout (folder drop-down, full-width list, full-screen message with Back, full-screen compose).
  - **Folders:** Explorer, My Computer and Recycle Bin without the task pane; Details becomes a list.
  - **System apps:** reflow to one column.
  - **Notepad:** tappable menus.
  - **TuneMole:** condensed results.
- **M2-02 (Web Explorer):** pages lay out at 800 px and fit the phone with CSS `zoom` (Fit to screen / Actual size, persisted), a condensed 36 px toolbar, and a Favorites sheet. Every site was crawled on day 1 and day 10.
- **M2-03:**
  - **Paint:** tool and colour strips, a phone-sized canvas, one-finger draw and two-finger scroll, and secondary colour by long-press.
  - **Snapshot Booth:** stacked, front camera.
  - **Amplifier:** the skin zoomed to fill the screen with 36 px buttons and the long-press playlist menu.
- **M2-G (this gate):**
  - `tests/e2e/v06-m2.spec.ts` (default suite):
    - **Phone, portrait and landscape:**
      - A rotation mid-use keeps an open Mail message and Back in view, and Web Explorer's fit zoom follows the new width.
      - The on-screen keyboard (a shorter viewport) never hides Mail's body or the address bar.
      - In landscape, Display, User Accounts and Dial-up scroll to their last controls.
    - **Tablet:** Web Explorer stays at actual size with the Favorites side pane, and Mail keeps its folder list and reading pane.
    - **Desktop (1280×800):** Mail and Web Explorer keep their v0.5 layout.
  - `tests/e2e/v06-review-m2.spec.ts` (`@review`) takes the screenshots below:
    - It opens every app by touch in either language.
    - On a phone it measures every window's Close button, the Web Explorer menu bar and My Computer's Credits link (36 px).
    - It lists every visible control under 36 px per app as a `small-targets.json` attachment, for this review.
    - It fails on sideways page scroll, on a window gone from the screen, and on any console or page error.

    All runs pass on every device.

## How to try it

`npm run dev`, then open `http://localhost:5173/still-online/?speed=fast` in Chrome DevTools device mode (Pixel 7, then rotate; or a 1024×768 touch tablet). On a real phone, run `npm run dev -- --host` and open the network URL on the same Wi-Fi.

- **Apps:** tap a desktop icon, or Start → All Programs → a folder → the app. Display Properties: long-press the desktop → Properties.
- **Messenger:** tap Sign in; Jess nudges and her chat opens full screen. Tap a reply, then Send.
- **Mail:** tap Send/Recv, tap a message, then Back; Reply opens a full-screen compose.
- **Web Explorer:** tap Connect on the offline page, then type an address such as `searchly.example`. View → Actual size scrolls the page sideways.
- **Paint:** draw with one finger, scroll with two, and long-press a colour for the secondary.

Run the review with `npx playwright test v06-review-m2 --grep @review --project phone` (also `phone-landscape`, `tablet`, and `chromium` for the desktop shot).

## Fixes made in this gate

All fixes are scoped to `[data-device='phone']` (or touch devices) unless noted, so the desktop is unchanged.

- **Display, User Accounts and Dial-up in landscape (412 px tall):**
  - Display's tab panel already scrolled: phones use overlay scrollbars, so none is drawn, and the theme list is below the preview. Its panel items and User Accounts' groups are now kept at full size (`flex-shrink: 0`), so a short panel scrolls instead of squeezing them.
  - Dial-up's dialog had no scroll at all, so its Dial / Cancel / Properties buttons were cut off. It now scrolls (`overflow-y: auto`).
  - A new test scrolls each of these dialogs to its last control.
- **Toasts over a full-screen chat (the M1 follow-up):** on a phone up to three toasts stacked over the chat's header and transcript. Now only the newest shows; the others still time out (`Toast.module.css`).
- **Amplifier:** on a phone the playlist starts open, because the full-screen skin was about 75 % empty. `v06-m2-03.spec.ts` now asserts the playlist is open instead of tapping it open, since that tap would now close it.
- **Snapshot Booth:** the tall portrait stage letterboxed the 4:3 picture in thick black bars. The stage is transparent on a phone.
- **Paint:** on touch devices the status bar said "Left click … right click". It now gives a touch hint (EN + DE), which wraps on a phone.
- **Tap targets:**
  - The Web Explorer menu items get `min-width: 36px`, because German's „?" (Help) was 24 px wide.
  - My Computer's Credits link is a 36 px row (new `MyComputer.module.css`).
- **Messenger's „Show what I'm listening to" checkbox** was invisible on every device. xp.css hides the native input and draws the box on `input + label`, but the input was nested inside its label. It is now `input` + `label`, so the box also appears on the desktop. That is a bug fix, not a look change.
- **Test fix:** `v06-review-m1.spec.ts` reads the newest toast (`.last()`), since a phone shows only that one.

## Known gaps and follow-ups

- **Games (M3):** Mines' cells are 16 px. Hen Hunt is letterboxed, and its German logo is clipped in portrait. Pinball's playfield is cropped in landscape. M3-01 adapts all of them.
- **Website content in Fit to screen:** links on the 800 px pages are small at a phone's zoom (about 0.5), as M2-02 intended (no per-site redesign). Actual size and the 36 px toolbar remain.
- **Pre-existing desktop looks, left as they are because fixing them would change the desktop:**
  - Notepad's menu items are 75 px wide (xp.css's button `min-width`), most visible on a tablet.
  - Mail's column header ends at the last column on a wide list.
  - Regional's single „Languages" tab is drawn like a button.
  - Dialogs (Display, User Accounts, …) show Minimize and Maximize on a tablet and the desktop.
- **Tablet Amplifier:** its own title bar is 20 px, not 36 px. The tablet's 36 px title bar rule covers XP windows only, so this is a small follow-up.
- **Phone tray:** the language badge's „EN"/„DE" touches its right border in landscape. This is cosmetic and belongs to the M1 shell.
- **Review flake:** one parallel review run once shot the desktop instead of the Phone Amplifier (window opened, then off screen). Three later runs didn't reproduce it, and the review spec now fails if a window leaves the screen after its shot.
