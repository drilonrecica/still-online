# v0.3 P1 — Every UI string in German: gate review

## What was built

- **P1-01** OS shell strings: boot, login, desktop, taskbar, tray, Start menu, window buttons, balloons, toasts, screensaver, pet, assistant, fs views, wallpaper/theme names.
- **P1-02** Messenger UI strings (contact list, chat chrome, statuses, transcript templates, away dialogs).
- **P1-03** Web Explorer shell, Dial-up, Mail UI and TuneMole UI.
- **P1-04** Accessories: Notepad, Paint, Snapshot Booth ("Fotobox"), Display Properties, Disk Cleanup, My Computer, Explorer.
- **P1-05** Amplifier (player, playlist, equalizer, skins, Burn CD).
- **P1-06** Games: Mines, Hen Hunt, Desktop Wrecker including canvas text.
- **P1-07** Star Pinball ("Sternen-Flipper") including the dot-matrix display.
- **P1-08** German layout pass (desktop icons, labels, narrow dialogs).

## How to try it

1. `npm run dev` (add `?speed=fast`), open the page in a German browser or pick **Deutsch** in the login screen's **Language / Sprache** box.
2. Log on and open any desktop app; titles, menus, buttons, dialogs and tooltips are German.
3. Flip the **EN/DE** tray badge: open windows follow live.

## Fixes made in this gate

- **Title-bar buttons were blank in German.** xp.css draws the minimize/maximize/close icons from `button[aria-label=Minimize|Maximize|Restore|Close]`, so localizing `aria-label` removed the icons. `src/os/wm/Window.tsx` now keeps the English `aria-label` as a styling hook and carries the German accessible name via `aria-labelledby`. Unit test added in `Window.test.tsx`; e2e specs still address the buttons by their localized names.
