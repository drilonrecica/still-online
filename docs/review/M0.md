# M0 — Foundation: gate review

## What was built

- **M0-01** Vite 6 + React 18 + TypeScript scaffold, ESLint, Prettier, Vitest (jsdom), `base: '/still-online/'`, `npm run verify`.
- **M0-02** Playwright (Chromium only) against `npm run build && npm run preview` on port 4173; smoke spec.
- **M0-03** CI workflow: verify + e2e on PRs and pushes to `master`.
- **M0-04** GitHub Pages deploy workflow (`.nojekyll` shipped from `public/`).
- **M0-05** Pages source set to GitHub Actions (owner).
- **M0-06** `CREDITS.md`, asset directory skeleton (`src/assets/icons`, `src/assets/emoticons`, `public/music`), README credits link.

## How to try it

1. `npm ci`
2. `npm run dev` — page shows the `still-online` heading.
3. `npm run build && npm run preview` — open `http://localhost:4173/still-online/`.
