## v0.2 in one paragraph

A local, fictional 2007: an XP-like desktop with a virtual file system, Display Properties, screensavers and balloon tips; a day-aware Messenger for six friends with away messages, history, winks and custom emoticons; a fictional web (Web Explorer, Searchly, Spaceport, a cursed fan page, a gossip blog, a school site), Mail and TuneMole; Paint and Snapshot Booth (webcam stays local); an Amplifier with skins, EQ and playlist editing; and Mines, Hen Hunt, Star Pinball, Desktop Wrecker, Fluff and Stapley. Each power cycle is a new day, days 1–5 carry the storylines. See `docs/release-notes-v0.2.0.md`.

## How to try it

1. `npm run dev`, open `/?speed=fast`, boot and log on.
2. Open Mail (Send/Recv), and Web Explorer (Connect) → `spaceport.example/jess` and `tinfoilcomets.example/guestbook`.
3. Start → Turn Off Computer, click the off screen, log on again: the boot screen says "Day 2". Repeat for day 3 and compare.
