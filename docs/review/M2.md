# M2 — Messenger: gate review

## What was built

- **M2-01** Content types, content-format doc and content lint (graph + text checks).
- **M2-02** Conversation engine (triggers, queueing, resume, typing, nudges) and persisted progress store.
- **M2-03** Messenger window: sign-in, status, personal message, grouped contact list.
- **M2-04** Chat window: transcript, reply choices, emoticons, nudge shake.
- **M2-05** Six contacts with opening scripts and timed / now-playing / nudge reactions.
- **M2-06** Sign-in and message toasts.
- **M2-07** Now-playing (event side).
- **M2-08** Messenger E2E spec (`tests/e2e/messenger.spec.ts`).

## How to try it

1. `npm run dev`, boot, log on.
2. Double-click Messenger, click Sign in. Add `?speed=fast` to the URL to run contact timers at 1/100.
3. Contacts sign in over the first ~5 minutes (Jess after 8 s, Dex after 4½ min); click a toast or double-click a contact.
4. Pick a reply, press Send; try Nudge. Reload: transcripts and script progress persist.

## Checks run in this gate

- `npm run verify` and `npm run e2e`: pass.
- `@review` specs (`review-m0`, `review-m1`, `review-m2`): pass, no console errors or warnings.
- **Every script, every path, played through.** `src/content/contacts/playthrough.test.ts` replays all choice paths of all 19 scripts (154 paths) through the real engine with fake timers: each ends cleanly, leaves no active script and never leaves an unresolved `{placeholder}` in the transcript.
- **Every opening played through the UI** on the fast clock (`tests/e2e/review-m2.spec.ts`): each contact signs in, opens, offers ≥ 2 rounds of choices and finishes. Contacts alternate first/last reply.

## Fixes made in this gate

- **Jess / `who` node**: "WHO??? {name} they r the best band EVER" resolved to the player's name ("WHO??? Ada they r…"). Now names the band, "the tinfoil comets".
- **Contact list** showed raw emoticon codes (`:D`, `(L)`, `<3`) in names and personal messages; it now renders them as pictures like the chat window (`Messenger.tsx`, test adjusted).
- Added `src/content/contacts/playthrough.test.ts` and `tests/e2e/review-m2.spec.ts`.

## Known gaps and follow-ups

- Sounds (nudge, toast) were not audited by ear in this headless gate.
- Now-playing reactions can only be exercised with a fake track until the Amplifier arrives (M3).
- Emoticon rows are a few pixels taller than text-only rows in the contact list; cosmetic.
