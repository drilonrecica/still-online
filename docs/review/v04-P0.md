# v0.4 P0 — Foundations gate (self-review)

## What was built

- **P0-01** Spaceport is now **Friendspace** (`friendspace.example`): new host, folders, catalog keys, logo, and every visible name in EN + DE. `legacyHosts.ts` redirects old `spaceport.example` addresses, links, favorites, history and restored windows to the new host. Ids such as `d2-spaceport-views` and `d4-spaceport-comment` are unchanged on purpose.
- **P0-02** v0.4 architecture and data model (`docs/architecture-v0.4.md`): new content types, `LocaleContent` fields and accessors, `web` store fields with sanitize and migrations (the v0.3 Top 8 migrates), and empty content modules with German placeholders. No UI.
- **P0-03** Top 8 drama engine: `onTop8Dropped` / `onTop8Readded` triggers, events between the web store and Messenger, reaction bookkeeping, wall entries, lint support.
- **This gate:** an extra flow test in `tests/e2e/v04-p0.spec.ts` (home, a friend profile, `/me`, `/me` through the old host) and the `@review` spec `tests/e2e/v04-review-p0.spec.ts`.

## How to try it

1. `npm run dev`, open `http://localhost:5173/still-online/?speed=fast`, log on.
2. Open **Web Explorer**, click **Connect**.
3. Visit `friendspace.example`, `friendspace.example/jess` and `friendspace.example/me`.
4. Redirect: type `spaceport.example/jess`. The address bar becomes `friendspace.example/jess`. An old "Spaceport" favorite also opens Friendspace.
5. Switch the language with the tray badge and look again.
