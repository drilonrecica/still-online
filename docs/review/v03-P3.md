# v0.3 P3 — Release-ready gate (self-review)

## What was built

- **P3-01** Bilingual e2e: German happy paths (`i18n-de-flow`), browser-language detection (`i18n-detect`), the picker/app/tray staying in sync (`i18n-language`), a live mid-game switch that re-renders open chats, mail, files and window titles (`i18n-switch`), and the v0.2 save migration (`i18n-migration`).
- **P3-02** Docs: README „Deutsch" section with `docs/screenshots/desktop-de.png`, `docs/release-notes-v0.3.0.md` (English plus a German summary), architecture and content-format docs pointing at `docs/i18n.md`, CREDITS for the Regional icon.
- **This gate:** `tests/e2e/v03-p3.spec.ts` (default suite) and the `@review` spec `tests/e2e/v03-review-p3.spec.ts`.

## How to try it

1. `npm run dev`, open `http://localhost:5173/still-online/?speed=fast` in a German browser (or pick **Deutsch** in the login screen's **Language / Sprache** box) and log on.
2. Day 1: open **Messenger**, sign in and answer Jess; read **Mail** (**Senden/Empfangen**); visit `spaceport.example/jess` in **Web Explorer**.
3. **Start → Ausschalten**, click the black screen: „Tag 2". Open several windows, then **Start → Alle Programme → Systemprogramme → Regions- und Sprachoptionen**, choose English, **Übernehmen**: every open window turns English in place.
4. **Start → Turn Off Computer**: Day 3 boots in English. In the login screen switch **Language / Sprache** back to Deutsch before logging on.
5. The **EN/DE** badge in the tray flips the language at any time.

## Fixes made in this gate

- **Register:** Messenger's incoming nudge and wink lines said „{name} hat dir einen Nudge/Wink geschickt" while the outgoing ones said „Sie". They now say „hat Ihnen …" (system UI uses „Sie").
- **Typography:** the German paragraph of `docs/release-notes-v0.3.0.md` closed „Regions- und Sprachoptionen" with an ASCII `"`; now `“`.
- **Flaky unit test:** `src/apps/paint/strings.de.test.tsx` failed in `npm run verify` because the lazy-loaded Paint module took longer than `findByRole`'s 1 s default to transform cold. The test now imports `./Paint` in `beforeAll`, so the lazy component resolves at once.
- Decisions logged in `docs/decisions.md` (P3-G lines).

## v0.3 in summary

v0.3 makes still online bilingual. A small typed i18n layer (`t()`/`useT()`, typed catalogs, locale-aware dates and numbers, no runtime library) drives every string in the shell, all apps and the games, including canvas text. Persisted state is language-neutral (ids and params, rendered at view time), so a switch changes everything on screen, including chats, mail and files that already happened, and v0.2 saves migrate in place without a wipe. The language comes from the browser on the first visit and can be changed in the login screen, in Regional and Language Options and from the tray badge, live and without a reload. All authored content (six friends over five days, mail, seeded files, Spaceport profiles, every site, balloons, Tacki and TuneMole) was rewritten for a German 2007 rather than translated, with the same ids and storylines underneath and parity and fallback tests guarding the overlay. The phase gates covered architecture (P0), UI strings (P1), content (P2) and release readiness (P3), each with EN/DE screenshots. The build is release-ready; tagging, pushing and publishing are left to the owner.
