# v0.6 M1 — touch shell gate

M1 adapts the XP shell to touch. This gate checked it on a phone (412×915 portrait, 915×412 landscape), a tablet (1024×768) and the desktop (1280×800), in English and German, plus one set as a boy. It applied the gate procedure and the touch rubric.

## What was built

- **M1-01 (window manager):**
  - **Phone:** every window renders maximized without storing it, has no Maximize/Restore, drag or grips, and has a 36 px title bar with 36×36 buttons.
  - **Tablet:** 36 px title bars, 32 px buttons, 16 px touch zones on the grips, and oversize windows open maximized.
- **M1-02 (shell pieces):**
  - a 40 px touch taskbar (icon-only window buttons on a phone) and the tray's „‹" Show hidden icons flyout
  - a phone Start menu that fits the screen, with All Programs as a panel with Back; flyouts open on tap on a tablet
  - toasts, balloons, Stapley and dialogs sized for the screen
  - the stacked phone login
  - screensaver dismiss on touch
- **M1-G (this gate):**
  - `tests/e2e/v06-m1.spec.ts` (default suite):
    - **Phone:** windows stay full-screen through a rotation, Notepad stays above a simulated on-screen keyboard, and the close dialog fits. With ten windows open, the front window's taskbar button scrolls into view.
    - **Tablet:** windows float with 36 px title bars, four labelled taskbar buttons fit, and windows stay on screen in portrait.
    - **Desktop:** 1280×800 opens floating windows over the 30 px taskbar.
  - `tests/e2e/v06-review-m1.spec.ts` (`@review`) takes the screenshots below. On a phone it measures a sample of tap targets with `boundingBox()`:
    - Start menu items and the All Programs Back row and folders (36 px)
    - taskbar window buttons (40 px)
    - title-bar Minimize/Close (36 px)
    - Stapley's Hide link, the dialog buttons and the toast close (36 px)

    It checks for sideways scroll and fails on any console or page error. The run passed on every device.

## How to try it

`npm run dev`, then open `http://localhost:5173/still-online/?speed=fast` in Chrome DevTools device mode (Pixel 7, then rotate; or a 1024×768 touch tablet). On a real phone, run `npm run dev -- --host` and open the network URL on the same Wi-Fi.

- **Log on:** tap the screen, type a name, tap Girl or Boy and the language, then tap Log On.
- **Start:** tap **start**, then **All Programs**: folders unfold in place, and **Back** returns to the menu. On a tablet the flyouts open on tap.
- **Windows:** open the Start menu's places (My Documents, My Pictures, My Computer, Recycle Bin) and switch between them from the taskbar.
- **Hidden tray icons:** tap the „‹" chevron for network, Messenger and Fluff.
- **A dialog:** type in Notepad and close it for the save prompt.
- **A toast:** sign in to Messenger for the friends' sign-in toasts.

Run the review with `npx playwright test v06-review-m1 --grep @review --project phone` (also `phone-landscape`, `tablet`, and `chromium` for the desktop).

## Fixes made in this gate

- **Stapley's balloon on a phone:** the options and Hide link were 11 px text links, and Stapley's 0.8 scale shrank them to about 9 px tall. On a phone each option (and each row of his long-press menu) is now a full-width 45 px row, which is 36 px once scaled (`Assistant.module.css`).
- **XP dialog buttons on a phone:** these were 23 px. `[role='dialog'] .window-body button` now gets `min-height: 36px` on a phone (`global.css`), which covers Notepad's save prompt and the other app dialogs.
- **Toast close (×) on a phone:** it was 16×16 px. It is now a 36×36 px corner target, and the text keeps clear of it (`Toast.module.css`).
- **Tablet taskbar:** the labelled window buttons were rigid 160 px (`flex: 0 0 160px`), so with four windows the fourth scrolled out of sight beside the full tray. They now shrink to the specified 110 px minimum before the row scrolls (`flex: 0 1 160px`).
- **Touch taskbar scrolling:** when the row does scroll (a phone with many windows, a portrait tablet), the front window's button scrolls into view (`Taskbar.tsx`, touch devices only).

- **Test fix:** `v06-m1-02.spec.ts`'s desktop taskbar screenshot failed at single-digit hours, because the masked clock's width shifts the tray. It now pins the page clock to 12:49, the baseline's time.

## Known gaps and follow-ups

- **Explorer's task pane** ("File and Folder Tasks": Restore, Empty Recycle Bin, …) still uses small text links on a phone. This belongs to the folder layouts in M2-01.
- **Toasts during a chat:** on a phone, up to three toasts can cover a full-screen chat's reply row for their 4 s. They can be closed with the 36 px ×. M2-01 (Messenger) may want to move them.
- **Tablet login:** the tablet login uses the desktop layout, so the name field is the desktop's small 20 px field. The specs only change the phone login. A touch-sized field on a tablet would be a small follow-up.
- **Phone login:** in portrait the wordmark sits at the top with empty space above the prompt. It is usable and unchanged from M1-02.
