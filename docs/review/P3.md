# P3 — Messenger depth: gate review

## What was built

- **P3-01** Away messages: auto-Away on idle (`awayMinutes`), a manual Away prompt, "(Away: brb)" in the header, `whileAway` flags, the "While you were away" toast, and `Contact.awayReply` (Jess, Marco).
- **P3-02** Message History: per-contact transcript browser with date separators, search and Clear History; opened from File → View Message History… and each chat's History button.
- **P3-03** Display pictures: pick any My Pictures image (or none); shown in the contact-list header and chat windows, with a fallback for missing files.
- **P3-04** Winks: 6 original animated winks, a "Winks ▾" menu, transcript entries, and `ContactLine.wink` (Jess hamster, Kayla hearts, Pia pickle).
- **P3-05** Emoticons++: 6 new built-in emoticons and custom emoticons made from your pictures, via the chat's emoticon picker.

## How to try it

1. `npm run dev`, open `/?speed=fast` (the fast clock scales delays by 1/100), boot, log on, open Messenger → Sign in.
2. Status dropdown → Away → OK; wait a few seconds, then set Online: the "While you were away" toast appears.
3. File → View Message History…, or a chat's History button.
4. In a chat: Winks ▾ → Hamster; 😊 ▾ → pick an emoticon or Create emoticon….
