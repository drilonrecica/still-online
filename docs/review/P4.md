# P4 — Internet: gate review

## What was built

- **P4-01** Web Explorer: IE6-style chrome, per-window history, dial-up load bar, the offline "page cannot be displayed" page with Connect, favorites, `browser:open` router, and the site framework (`SITES`, `resolve`).
- **P4-02** Searchly: home, ranked results over every registered page, "Did you mean", I'm Feeling Lucky, the never-finishing toolbar installer.
- **P4-03** The cursed Tinfoil Comets fan page: home (hamsters, marquee, hit counter, webring, MIDI), band, pics, and a guestbook friends sign by day and the player can sign.
- **P4-04** Spaceport: landing page, six themed friend profiles by day, and an editable `/me` profile.
- **P4-05** Celeb Gossip 07 (posts by day, tags, hot-or-not poll, comments), Westfield High, VirusGuard 2007 parody.
- **P4-06 / P4-07** Mail: folders, compose, auto-replies, bounce, attachments, and five days of mail content.
- **P4-08** TuneMole: search over fictional peers, a download state machine (track / prank / stall), Library.

## How to try it

1. `npm run dev`, open `/?speed=fast`, boot, log on.
2. Open **Web Explorer** on the desktop and press **Connect**; Searchly loads.
3. Search "tinfoil", follow results, sign the guestbook, visit `spaceport.example/jess`.
4. Start → All Programs → **Mail** (press Send/Recv) and **TuneMole** (search "surf", Download).

## Checks run in this gate

- `npm run verify`: pass (1032 unit tests).
- `npm run e2e`: pass (24), including the new `tests/e2e/v02-p4.spec.ts` (search → fan page → guestbook; Mail delivery; TuneMole download).
- `@review` spec `review-p4.spec.ts`: pass, no console errors or warnings.
- Content rubric: friends' voices hold (Marco's own lines have no "!", Jess in caps, Kayla's drama, Theo apologises, Pia bossy); only `.example` domains; storylines (concert, bio project, Velvet Lantern, ponies) agree between mail, sites and profiles.

## Fixes made in this gate

- **Westfield High header collapsed** (`Westfield.module.css`, `Layout.tsx`): `display: flex` on the header `<td>` dropped its `colSpan`, squeezing the maroon banner into the sidebar width and leaving a white gap. The flex now lives on an inner wrapper.
- **Anachronism**: Kayla's gossip-blog comment used a `@name` reply convention; changed to a plain name.
- Added the P4 e2e flows and the `@review` spec; shared helpers `openBrowserOnline`, `go`, `openFromStart` in `tests/e2e/helpers.ts`.

## Known gaps and follow-ups

- Mail compose/reply, auto-replies and attachment save, TuneMole prank files and the `/me` profile editor are covered by unit tests, not by e2e flows or screenshots.
- Gossip `/tag` with no tag selected shows only the tag list on an otherwise empty page.
- Below-the-fold content (hit counter, webring, comment walls) is not in the screenshots, which capture the 800×600 window's first screen.
