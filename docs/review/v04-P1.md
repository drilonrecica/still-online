# v0.4 P1 — Friendspace + GlitterCodez gate (self-review)

## What was built

- **P1-01 Bulletins:** `/bulletins` page (day-gated, from content), the newest 3 on `/me`, and an unread dot in the nav that stays until the page is opened that day (`bulletinsSeen`).
- **P1-02 Band pages + player + autoplay:** `/band/<id>` with a dark inline `BandPlayer` that drives Amplifier, profile-song autoplay (only when unmuted, idle and enabled) with a stop button, and a `/me` autoplay setting. Bands are linkable from the Top 8.
- **P1-03 Layout codes + profile extras:** the total `layoutCode.ts` parser and its generator, background/font/sticker/cursor sets, the `/me` editor textarea with live preview, glitter headline, stickers, sparkle cursor trail, comment graphics and mood history. There is no raw CSS/HTML path.
- **P1-04 GlitterCodez:** `glittercodez.example` with a layout gallery (live mini previews, copy boxes), `/glitter`, `/stickers`, `/cursors` and the 2007 look. Every code comes from `layoutCodeFor`.
- **P1-05 Top 8 editor + drama UI:** add, remove and reorder friends, bands and extras (max 8), drop/re-add reactions on the `/me` wall, mood history saved on mood change.
- **This gate:** a flow test in `tests/e2e/v04-p1.spec.ts` (bulletins, a gallery code pasted into `/me`, Top 8 edit and save), the `@review` spec `tests/e2e/v04-review-p1.spec.ts`, and the fixes below.

## How to try it

1. `npm run dev`, open `http://localhost:5173/still-online/?speed=fast`, log on.
2. Open **Web Explorer**, click **Connect**.
3. `friendspace.example/bulletins`: one bulletin on day 1. The "Bulletins (new)" nav entry loses its "(new)" once you open the page.
4. `friendspace.example/band/tinfoil-comets`: the player starts playing; Pause and Play work.
5. `glittercodez.example`: pick a layout, press **Copy code!!** (or select the box and press Ctrl+C).
6. `friendspace.example/me` → **Edit Profile** → paste into **Layout code**; the preview updates. Reorder, remove or add Top 8 entries, then **Save Changes**.
7. Switch the language with the tray badge and look again.

## Fixes made in this gate

- **Bulletin sender picture** sat inline in the "From:" line and pushed the text down. `.bulletinPicture` was written for a flex parent but lives in a block, so it now floats left and the text wraps beside it (`/bulletins` and the `/me` box).
- **`go()` e2e helper** failed on pages with their own live regions: GlitterCodez tiles have an empty `role="status"` each. It now targets the last status, the browser's status bar.

- Stapley's balloon covers the bottom-right of the browser content (existing behaviour).
